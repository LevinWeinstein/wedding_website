# Project Overview: Katie & Levin's Wedding Website

This project is a high-fidelity, responsive wedding website built to match a specific aesthetic and functional requirements.

## Tech Stack
- **Frontend**: React (Vite)
- **Styling**: Vanilla CSS with a focus on custom design tokens and responsive media queries.
- **Interactivity**: 
  - `yet-another-react-lightbox` for the photo gallery.
  - Custom React state management for tabs and mobile navigation.
- **Backend (RSVP)**: Google Sheets + Google Apps Script (Serverless API).

## Key Features
- **Dynamic Mobile Header**: Sticky top bar that changes its title based on the active tab.
- **Hand-Drawn Aesthetics**: Integration of custom illustrations (floral borders, decorative bows) with responsive visibility logic.
- **Serverless RSVP**: A secure, searchable guest list system that requires no traditional database or hosting costs.
